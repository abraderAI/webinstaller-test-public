# webinstaller-test-public

Public test repo for exercising the [`deftai/webinstaller`](https://github.com/deftai/webinstaller) upgrade flow.

Used to validate:
- GitHub App install permissions on a public repo
- Preview-PR rendering
- DEFT Live **triptych** visualization (3 cinematic cameras on a single public repo)
- Bootstrap engine artifact delivery (`.deft/core/`, `AGENTS.md`, `.deft/VERSION`)

Do not rely on the content here for anything else.
